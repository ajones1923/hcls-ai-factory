# House style — the shared look for all 18 storyboard frames

Every prompt (`01`–`18`) now embeds this exact **HOUSE STYLE** block at the top of its prompt,
so the whole set renders as one cohesive visual storyboard of the TSC AI Engine. If you tweak
the look, change it here and in every prompt identically — or, better, generate one frame you
love and feed it back into Nano Banana Pro as a **style-reference image** for the other 17.

## Conventions used throughout (the storyboard's visual grammar)

- **Gold (#FFD166)** = the things that matter most: key numbers, the "recovered" idea, the takeaway.
- **Sky-blue (#7FB0FF)** = the engine / the uncertainty glass.
- **Teal-green (#2FA37A)** = "normal / controlled / deterministic / solution."
- **Warm-red (#E5484D)** = "disease / threshold / problem."
- **Gray (#5B6275)** = "the old way / the missed signal."
- Every frame carries the SYNTHETIC · decision-support · not-FDA-cleared honesty — it is part of
  the credibility, not fine print.

## Production tips (for a clean, consistent batch)

1. **Generate one anchor frame first** (e.g., `01` or `05`), get the look right, then use it as a
   style-reference for the rest so the palette/typography stay locked.
2. **Two-pass text** for the dense frames (`05`, `10`, `15`): generate the layout, then *"keep the
   exact layout but regenerate only the text so every label is sharp and correctly spelled."*
3. **Generate 2–3 variants each** and keep the best — generation variance is real.
4. **Brand names** (NVIDIA, Omniverse, RunPod, Claude) render as plain text labels only — never as
   attempted logos; verify spelling.
5. Keep the **NN / 18 corner index** on every frame so the printed/displayed set is self-ordering.
