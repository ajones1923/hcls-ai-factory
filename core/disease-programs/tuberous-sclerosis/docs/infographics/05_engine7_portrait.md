## Tips

- Dense infographics are the hardest case for any image model. If text crowds or misspells,
  do a **second pass**: *"keep the exact layout but regenerate only the text so every label is
  sharp and correctly spelled."*
- Every stat is truthful to the build (19,389-term HPO, 100% ACMG accuracy, +12-pt detection,
  6/6 mosaics, 13 event types, the tier names). Keep the "construct validity / SYNTHETIC /
  not FDA-cleared" labels — they are what make it credible to a clinical audience.
