  highlighted panel, not small print."*
- All numbers are truthful to the engine's evaluation harness. Keep the SYNTHETIC / construct-
  validity / not-FDA-cleared labels — they are the point.
- Second pass for text: *"keep the exact scorecard layout but regenerate only the text so every
  label is sharp and correctly spelled."*
