## 1. What this subject does

- **`esmfold-model`** — Real single-sequence protein structure prediction (sequence -> PDB + per-residue pLDDT). GPU-served on the GB10 (cu130 torch + half-precision): VCP-scale (806 aa) in ~1s, ~6x faster than CPU. POST /fold.

- **`esm2-search`** — ESM-2 (650M, 1280-dim) embeddings on the GB10 GPU + Milvus similarity search. Verified: ubiquitin query self-retrieves cosine=1.0, variant 0.997. Reuses the platform vector DB. POST /embed /index /search. B3: optional exact Smith-Waterman re-rank (Biopython local alignment) on the ANN top-k for retrieve-then-rerank precision (%identity + alignment score).

- **`protein-developability`** — B4 developability scoring: real biophysical proxies (GRAVY, Guruprasad instability index, pI, aromaticity, MW) + flag/verdict. B3 design: developability-guided single-point mutation optimizer (proposes substitutions that lower instability, computed). Verified: E31K lowers instability 36.0->28.2. Structure-conditioned design (ProteinMPNN/RFdiffusion) + MHCflurry immunogenicity = follow-on. POST /sc

- **`mhcflurry-immunogenicity`** — MHCflurry 2.x (Apache-2.0) class-I HLA presentation prediction. Reference result: NLVPMVATV vs HLA-A*02:01 -> presentation 0.97 / 17nM (correct strong epitope). Sliding-window scan -> per-allele immunogenic-epitope burden for biologic developability + neoantigen pre-screen. POST /scan /predict. The mhcflurry package is not installed on the reference box (import fails), so the service cannot start

- **`proteinmpnn-design`** — Structure-conditioned sequence design (MIT): backbone PDB -> amino-acid sequences predicted to fold into it, with ProteinMPNN score + native seq-recovery. Verified: 5L33 backbone -> designs at ~45% seq-recovery (expected range). Chains to ESMFold for re-fold validation + to de-novo backbones. POST /design.

- **`esm2-finetune`** — Parameter-efficient (LoRA) domain fine-tuning of ESM-2 for a custom protein property (regression/classification) on the GB10 GPU. Reference result: learns lysine-count signal (loss 5.05->2.07) with only 1.2% trainable params. Path to bespoke solubility/activity/stability predictors without external repos. Library/in-process (finetune+predict). The peft dependency is not installed on the reference

- **`chai1-structure`** — Chai-1 (Apache-2.0 code+weights, commercial-OK): AlphaFold3-class multimodal structure prediction — proteins, small-molecule ligands, DNA/RNA, glycans, and COMPLEXES. Fills the complex co-folding gap ESMFold cannot (single-sequence only).
