## 1. What this subject does

- **`genomics-engine`** — GPU germline variant calling: FASTQ to BAM to VCF via accelerated alignment (fq2bam/BWA-MEM2) and DeepVariant. Script/pipeline-invoked (Parabricks in Docker via run.sh/run_caller.sh), not yet a request/response API. ClinVar/AlphaMissense annotation is served by the Precision Intelligence Engine (E2, :5001); E1 produces the QC'd variant substrate E2 annotates.

- **`variant-store`** — VCF -> DuckDB columnar store: SQL/region queries by chrom/pos/filter/sample, PASS-vs-RefCall aware, with Ts/Tv QC. Verified on real HG002 PASS SNVs: Ts/Tv~2.0 (human ~2.0-2.1). Adds a QC trust-gate report (Ts/Tv, het/hom, SNV/indel, verdict pass|warn|fail) at GET /qc that withholds interpretation on a bad call set. Plus a caller option (run_caller.sh: DeepVariant|HaplotypeCaller). POST /query /loa

- **`mosaicism-vaf`** — Read-backed VAF (AD/DP) per PASS call + low-VAF mosaic-candidate flag (default 0.02-0.35, DP>=30). The diagnostic trap standard germline pipelines drop (mosaic TSC1/TSC2). Evidence for the Rare Disease agent - NOT a classification. POST /mosaic on :8575.

- **`acmg-secondary-findings`** — Rules layer flagging annotated variants against a curated representation of the ACMG SF v3.2 gene list (82 genes / 40 conditions as curated here; ACMG has since published v3.3) with reportable (likely-)pathogenic significance. Deterministic gene x significance join over the annotation output. Validate panel vs official publication before clinical use.

- **`gwas-association`** — Single-box GWAS: per-variant logistic-regression association vs a binary phenotype (+ covariates, MAF filter, Manhattan output), pure Python (statsmodels), no Spark. Verified: detects a causal variant (p<0.001, OR>1) while a null variant is n.s.; separation handled gracefully. Complements the DuckDB variant store (E3) at single-box scale.
